# V2.6 Android build repair and catalog port

V2.5 CI failed before compilation: sdkmanager not found on ubuntu-latest (Ubuntu 26.04). Pin ubuntu-24.04 and provision Android SDK explicitly. Run independent JVM catalog tests before Android setup. The Android plugin now uses a shared Java catalog class and generated data from the two bundled open-film fixtures. This is a build-time data mapping, not a full Python rule interpreter or runtime network adapter. No existing upstream sources have been migrated. The generator intentionally accepts only the bundled open film format and reviewed demo media host; it is not an upstream crawler importer. No public JAR publication. Actual device compatibility and playback remain unverified.

Commands: bash engine/android/test.sh (JDK17 and Python3), bash engine/android/build.sh (also Android SDK 35). Production and preview remain unchanged.
