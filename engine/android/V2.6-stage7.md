# V2.6 stage 7 — restricted XHTML snapshot adapter

Version 2 registry adds html-snapshot with an inline object containing version:1, html, items selector, fields id/name/url. This accepts well-formed XML-compatible HTML only, without declarations, DTDs, processing instructions or external entities. The CSS subset is a single tag, class or tag.class selecting descendants. XPath subset is a relative direct-child path (./tag/child, up to five steps). Field selector may be null to select the current node; attribute can be text (direct text only), data-id or href. Script/style/iframe/object/template/noscript subtrees are excluded. Size, tree depth, node, row and selector bounds apply. Each mapped record must match the pre-reviewed canonical demo ID, title and media URL. No JavaScript, general browser parsing, XPath execution engine, remote page fetching or arbitrary website migration.

CI covers restricted selectors, malicious declarations, excluded nodes, duplicates, rejected URL and registry integration. The previous network workflow had passed JVM tests at time of implementation, with DEX pending. Android XML implementation and TV runtime compatibility remain unverified. Existing subscriptions unchanged. Original 755 upstream entries not migrated.
