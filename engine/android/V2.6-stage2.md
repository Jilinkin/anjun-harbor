Prior run passed independent JVM catalog tests, then setup-android failed attempting the removed package 'tools'. Set its documented packages input explicitly to platform-tools, platforms;android-35, build-tools;35.0.0. No Android compile result yet.

Add an inline JSON rule mapper in the native plugin. The optional ext string is a JSON object containing version, data, items (literal path array), and fields (id/name/url path arrays). Empty ext keeps the reviewed built-in catalog. Nonempty ext maps only a subset of the already reviewed two open demo records; identity, canonical name and URL must match. No URL fetching or executable code. Invalid input fails closed. This is a limited proof of runtime field mapping, not the full Python JSON/CMS/HTML engine. Tests exercise field mapping and rejection of unknown media with JVM org.json; Android actual behavior remains unverified. Existing subscriptions unchanged.
