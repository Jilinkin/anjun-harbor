# V2.6 stage 6 — first-party network transport

Stage 5 passed CI (45578178698). New explicit cms-network-demo kind reads the fixed Harbor-owned HTTPS metadata document. No arbitrary endpoint or redirects, no scripts, no cookies configured. Limits: 64 KiB, 5s connect/read timeout, best-effort 15s read deadline (not a strict DNS/connection deadline), response status 200 and identity encoding. Existing canonical title, URL and credit checks still apply. The network response can select/reorder the two reviewed open films; it cannot introduce new films or endpoints. No network provider by default. Only one network provider may be configured. Invalid provider shape is rejected before network access; all configuration failures remain fail-closed.

Optional inline ext:
    {"version":2,"providers":[{"id":"harbor","kind":"cms-network-demo","allow_network":true}]}

This is a first-party transport proof, not a generic external CMS crawler. Test transport uses a mock connection, no real external requests during tests. Native HTML adaptation, independent provider failures, real Android networking, actual playback and source authorization review remain pending. No production or five-warehouse preview changes.
