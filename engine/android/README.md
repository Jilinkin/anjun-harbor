# V2.5 Android ABI prototype

Original Java implementation for two CC BY 3.0 demo films only; see smoke/README.md for credits. ABI reference: https://github.com/takagen99/Box/blob/main/app/src/main/java/com/github/catvod/crawler/Spider.java and https://github.com/takagen99/Box/blob/main/app/src/main/java/com/github/catvod/crawler/JarLoader.java . Host class is com.github.catvod.spider.Harbor (api csp_Harbor). Init.init(Context) is a no-op. The compile-only host ABI shim is excluded from DEX. No remote code execution, website fetching, player extraction or port of the Python rules. Player gets only a fixed open film link for known IDs.

Build with JDK 17 and Android SDK platform 35 / build tools 35.0.0: bash engine/android/build.sh . CI uploads harbor.jar and SHA256 as an artifact after DEX class-definition validation. This checks structure, not actual client behavior. Test using a verified artifact and compatible client; config.example.json has an intentionally invalid placeholder URL. No public production JAR is created. The exact TV client and version remain unknown. Test plugin loading, home, categories, search, detail, playback, unknown ID. No actual device test or media availability confirmed. Existing production and five-warehouse preview unchanged.
