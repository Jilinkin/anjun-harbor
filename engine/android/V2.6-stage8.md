# V2.6 stage 8 — optional provider isolation

Stages 6 and 7 passed full CI (45578501032, 45578646036). Version 3 inline registry uses the same provider schema as version 2, but isolates individual provider load failures after whole-manifest structural validation. Versions 1 and 2 retain strict fail-closed semantics. Every provider remains subject to the exact canonical demo ID, title and URL checks. Valid records from a successful provider are merged atomically; invalid provider data is discarded in full. If all fail, the catalog is empty, not the default or stale catalog. Interrupted operations propagate. No automatic retries, caching or concurrency across providers.

The plugin publishes catalog and diagnostics together in an immutable holder. Home response includes harbor_status array; harborDiagnostics() exposes the same sanitized JSON for development, but a TVBox client may ignore both. Diagnostics contain provider ID, status, item count, unique count or bounded reason category; no raw URLs, exception messages or response payloads. JVM tests cover partial failure, duplicate count, rejection, no stale playback, all-failed state and reset. Actual Android networking and client display remain unverified. Only bundled reviewed open film records are supported. No original third-party interface migration; existing subscriptions unchanged.
